# Relevant reading

This project explores a narrow, applied version of the broader agent-control
problem. It does not claim to reproduce any of the linked results.

1. Anthropic (2026), **SLEIGHT-Bench: Finding Blind Spots in AI Monitors**.
   https://alignment.anthropic.com/2026/sleight-bench/
   Relevant observation: authorization confusion is a type of monitor blind spot.
2. Anthropic Fellows / collaborators (2025), **Strengthening Red Teams: A Modular
   Scaffold for Control Evaluations**.
   https://alignment.anthropic.com/2025/strengthening-red-teams/
   Relevant observation: controlled sabotage and monitoring tests need concrete
   objectives and realistic execution pathways.
